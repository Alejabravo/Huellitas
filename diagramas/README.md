# Diagramas UML y modelos C4 — Huellitas

Esta carpeta contiene los archivos editables de modelamiento del sistema Huellitas, desarrollados en Draw.io.

Incluye dos diagramas UML estructurales, dos diagramas UML dinámicos y cuatro niveles del modelo C4.

Los diagramas pueden abrirse y modificarse desde https://app.diagrams.net/.
